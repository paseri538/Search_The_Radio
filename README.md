# さーち・ざ・らじお！

『ぼっち・ざ・らじお！』のエピソードを探せる**非公式**の検索サイトです。

## このサイトを作ったわけ

『ぼっち・ざ・らじお！』を聴き返したいとき、「あの話、何回だったっけ？」「あのコーナーをまとめて聴きたい」と思っても、たくさんの動画の中から探し出すのはひと苦労でした。

そこで、**聴きたい回や場面にすぐたどり着けて、ラジオをもっと便利に楽しめるように**このサイトを作りました。出演者やコーナー、ちょっとした話題のキーワードから探して、その話が始まる時刻から再生できます。これから聴き始める方にも、お気に入りの回をもう一度楽しみたい方にも、気軽に使っていただけたらうれしいです。

---

## できること

- **キーワード検索**　タイトル・出演者・話題で探せます。ひらがな・読み・愛称でも見つかります
- **関連する語も候補に**　たとえば「ぶたいぼっち」と打つと、舞台のキャストの名前も検索候補に出ます
- **絞り込み**　出演者・公開年・コーナー・その他（公開録音・生配信）を組み合わせて絞れます
- **時刻へジャンプ**　キーワードやコーナー、本日のテーマなどのお題で探すと、その話題が始まる時刻から YouTube で開けます
- **お気に入り・タイムスタンプ**　気になった回や場面を、自分のブラウザに保存できます
- **ランダム・再生リスト作成**　適当に1回選んだり、表示中の回をまとめて再生したりできます
- **カラーテーマ**　ホワイト・ダーク・ピンク・イエロー・ブルー・レッド・グリーンの7色
- **スマホのアプリのように使える**　ホーム画面に追加すると、オフラインでも開けます（PWA）

## 検索・表示の決まり

<details>
<summary><b>検索のしかた・見た目の細かい決まり</b></summary>

- 検索は、タイトル・出演・キーワードを1つずつ区切って探します（別々のキーワードがつながって当たることはありません）。「～」と「〜」は同じ文字として扱います
- 検索語は、登録した読み・愛称でも探します（「かがやいたしゅんかん」→ 本日のテーマ「輝いた瞬間」、「げんさく」→ はまじあき など）。読み・愛称で見つかった回にも、その話の時刻へのリンクが付きます
- ひらがな2文字以下の検索（「さく」「かい」など）は、読みの頭が合うときだけ当てます（「さく」が「げんさくしゃ」に当たって、関係ない回が出ないように）。3文字以上は読みの途中でも当てます
- 2文字以下の読み（「いく」「さく」など）は、検索語がその読みそのもののときだけ使います（「長谷川育美」で関係ない回まで拾わないように）
- コーナーの中身（本日のテーマ・ぼっち予想テストのお題など）は、検索語そのものと、読みから当たった登録済みの表記で探します（「LINE」の読み「ライン」が、お題「友達だと思うライン」に当たらないように）
- 関連ワード（`related.json`）は検索候補に並べるだけで、検索結果には入れません
- 「#36 えろおんなじょうし」のように番号＋読みで探しても、時刻へのリンクが付きます
- コーナーで探すと、カードの「ゲスト：…」の行がその回の中身（ゲスト・曲・テーマ・問題・キャラクター）に変わります。中身を入れていない回はいつもの表示のままです
- 出演者・コーナー・年で絞ったときは、番号のない特殊回（京まふ大作戦・CENTRAL STATION など）も含めます
- 0件のときは、言い換えのヒントと「検索と絞り込みをリセット」のボタンを出します
- 灰色の補助の文字（公開日時・動画時間など）は、白地でもダークでもコントラスト比 5:1 以上にしています
- モーダル（このサイトについて・沿革・関連リンク・タイムスタンプ）を開くとフォーカスが中へ移り、閉じると開いたボタンへ戻ります
- 別のタブで登録・削除したタイムスタンプは、このタブにもすぐ反映されます
- 同じ条件の検索をやり直しても、「戻る」の履歴は増えません

</details>

## ファイルの構成

| ファイル | 中身 |
| --- | --- |
| `index.html`・`style.css`・`main.js` | サイト本体 |
| `sw.js` | オフライン用のキャッシュ（Service Worker） |
| `episodes.json` | 回の一覧（新しい順・1回1行） |
| `links.json` | 回ごとの関連リンク（X・Instagram） |
| `lucky-button.json` | 「ラッキーボタン」のゲスト |
| `kessokuband_watasi.json` | 「結束バンドと私」の曲 |
| `todays-theme.json` | 「本日のテーマ」のテーマ |
| `bocchi-test.json` | 「ぼっち予想テスト」の問題・お題 |
| `pickup-character.json` | 「ピックアップキャラクター」のキャラクター |
| `history.json` | 番組の歩み（沿革） |
| `keywords.json`・`readings.json` | 検索用の読み（キーワード／人名・愛称） |
| `related.json` | 関連ワード（ある語を打ったときに、一緒に検索候補に出す語） |
| `thumbnails/<回>.jpg` | サムネ（320×180。YouTube の mqdefault.jpg と同じ） |

## 公開のしかた

GitHub にアップ（push）すると、GitHub Actions（`.github/workflows/deploy.yml`）が自動で GitHub Pages に公開します。
`sw.js` の版の番号（`SW_VERSION`）は公開のたびに自動で書き換わるので、手で直す必要はありません。
