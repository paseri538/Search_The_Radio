# さーち・ざ・らじお！

『ぼっち・ざ・らじお！』の非公式検索サイト（https://searchtheradio.com/）。GitHub にアップすると、GitHub Actions（`.github/workflows/deploy.yml`）が GitHub Pages に公開します。

| ファイル | 中身 |
| --- | --- |
| `episodes.json` | 回の一覧（新しい順・1回1行） |
| `links.json` | 回ごとの関連リンク（X・Instagram） |
| `lucky-button.json` | 回ごとのラッキーボタンのゲスト |
| `kessokuband_watasi.json` | 回ごとの「結束バンドと私」の曲 |
| `todays-theme.json` | 回ごとの「本日のテーマ」のテーマ |
| `bocchi-test.json` | 回ごとの「ぼっち予想テスト」の問題・お題 |
| `pickup-character.json` | 回ごとの「ピックアップキャラクター」のキャラクター |
| `history.json` | 番組の歩み（沿革） |
| `keywords.json` / `readings.json` | 検索の読み（キーワード／人名・愛称） |
| `thumbnails/<回>.jpg` | サムネ（320×180。YouTube の mqdefault.jpg と同じもの） |
| `admin/` | **データ登録用の編集ツール**（手元専用） |

## 編集ツールで登録する

JSONを直接書かなくても、フォームに入力するだけで回・サムネ・検索ワード・沿革を登録できます。

1. `admin/start.command` をダブルクリック（ブラウザで `http://localhost:8790/admin/` が開きます）
   - 確認用サーバーは裏で動き続け、一瞬開くターミナルのウィンドウは自動で閉じます。Macを再起動するまでは、ブックマークした `http://localhost:8790/admin/`・`http://localhost:8790/` をそのまま開けます
   - もう一度ダブルクリックしても、動いているサーバーを使ってブラウザを開くだけです（サーバーもウィンドウも増えません）。以前の版（ウィンドウの中で動かしていたもの）が残っていたら、止めて1つにまとめます
   - **開いているページは、ファイルが変わると自動で新しくなります**（サイト・編集ツールを直した後も、コマンドを打ち直したり開き直したりしなくてよい）。詳しくは下の「確認用サーバーについて」
   - 初回に「開発元を確認できない」と止められたら、右クリック →「開く」で一度だけ許可してください
   - ターミナルで `python3 admin/serve.py` と打っても同じです（そのターミナルのウィンドウは閉じません）。8790 番が使用中なら 8791 番…を使います（ほかのサイトの編集ツールと同時に動かせます）。ブラウザを開かないときは `--no-browser`
   - **3つのサイトの編集ツールを切り替えられます**：左上のロゴ・サイト名を押すとメニューが開き、「ぼっち・ざ・ひすとりー！」「出演情報（YPIK SCHEDULE）」「さーち・ざ・らじお！」を選べます（いま開いているサイトに ✓。ほかのサイトは「起動中」か「停止中」）。停止中のサイトを選ぶと、そのサイトの確認用サーバーを起動してから移ります。未保存の変更があるときは、移る前にブラウザが確認します（キーボードでは Enter で開いて ↑↓ で選べます）
2. 画面上部のタブで切り替えます
   - **エピソード** … 左から「一覧／入力フォーム／サイトのプレビュー」。「＋ 新しい回」を押して YouTube のURLを貼ると、回・出演・配信日・動画時間・サムネが自動で入ります。あとはコーナー（時刻と、ラッキーボタンのゲスト・結束バンドと私の曲）・キーワード（時刻つき）・関連リンクを入力します
   - **検索ワード** … `keywords.json` と `readings.json` の表。右端の件数は、その語を含む回の数です（「該当なし」なら表記違い）。「試す」で保存前にヒット数の目安が分かります
   - **沿革** … `history.json` の出来事（新しい順に表示。保存すると日付の位置に入ります）
3. 編集した内容は保存するまで手元に溜まり、一覧に「● 未保存」「● 新規」「削除予定」と出ます（タブにも点が付きます）
4. 「保存」（⌘S）で、変わったファイルとサムネをまとめて書き込みます。**変えていない回の行は1文字も変わりません**（足した行・直した行は、各ファイルの新しい行と同じ書き方になります）
5. 右側のプレビューは**本物のサイト**で、入力するそばから（1秒ほどで）保存前の内容に描き直されます
   - 「この回」はフォームで開いている回をサイトで検索した画面（「#115」など）、「一覧」はサイトを開いたときの画面。「スマホ／PC」で幅を切り替え、↻ で読み直し
   - まだ保存していないサムネ（ドロップした画像・これから YouTube から取る画像）もプレビューには出ます
   - プレビューの中のカード（サムネ・タイトルの部分）をクリックすると、その回がフォームに読み込まれます。プレビューの中で検索・スクロールした状態は、描き直しても残ります。プレビューの中でも ⌘S で保存できます
   - 編集ツールの色は、サイトのカラーテーマ（ホワイト・ダーク・ピンク・イエロー・ブルー・レッド・グリーン）と同じになります。プレビューの中やサイトのタブでテーマを変えると、編集ツール・プレビュー・サイトのタブがすぐ同じ色に変わります
6. サーバーは止めなくてかまいません（このPCの中からしか開けず、Macの再起動・ログアウトで止まります）。止めたいときは `admin/stop.command` をダブルクリック

### 確認用サーバーについて

`admin/serve.py` は、サイトと編集ツールを配信し、編集ツールの保存・プレビュー・YouTube の読み取りを受け付けるサーバーです（起動・自動更新の仕組みは「ぼっち・ざ・ひすとりー！」「出演情報（YPIK SCHEDULE）」と共通）。

- **自動更新**：配信するHTMLに `admin/live.js` を差し込み、開いているページが1秒ごとに「ファイルが変わったか」を確かめます（裏のタブでは休み、表に戻った瞬間に確かめます）。公開用の `index.html` そのものには入らないので、公開したサイトでは動きません
  | 変わったもの | サイトのタブ | 編集ツール |
  |---|---|---|
  | `style.css` | 読み直さずにその場で差し替え | プレビューだけ差し替え |
  | `index.html`・`main.js` など | 読み直す（検索語などURLの状態はそのまま。ローディング画面は出さない。スクロールはいつもどおり先頭から） | プレビューだけ読み直す |
  | 10個のJSON・`thumbnails/*.jpg` | 読み直す（編集ツールで保存したときも） | エディタなど**ほかの場所**で書き換えたときだけ読み直す（編集ツール自身の保存では読み直さない） |
  | `admin/admin.js` など | ― | 読み直して、開いていた回を開き直す |
  - 編集ツールに未保存の変更があるうちは読み直しません。画面下に「編集ツールが新しくなりました。保存すると読み直します」と出て、保存すると読み直します（「今すぐ読み直す」で保存せずに読み直すこともできます）
  - ローディング画面を出さない仕組みのため、`main.js` には「`html` に `live-reloaded` が付いていたら、カードが並んだらすぐに表示する」分岐があります（`admin/live.js` だけが付ける印なので、公開したサイトの動きは変わりません）
- `admin/serve.py` 自体を書き換えたときも、動いているサーバーが自分で新しい版に入れ替わります。プレビュー用の保存前の内容はサーバーのメモリにあるので、入れ替わったときは編集ツールが送り直します
- 保存・エラーの記録は `admin/serve.log`（大きくなったら古い分から消えます）
- 裏に回さず、ターミナルの中で動かしたいときは `python3 admin/serve.py --here`（Ctrl+C で終了）
- 編集ツールのサイト切り替え（`admin/sites.js`）は `/admin/api/sites` で3サイトの状態を調べ、停止中のサイトはそのサイトの `admin/serve.py` を起動します（フォルダは `~/Downloads` に並んでいる前提。見つからないサイトはメニューに出ません）。`admin/live.js`・`admin/sites.js`・`serve.py` の起動まわり（「サーバー本体」から下）は3サイトで同じ内容です

入力を楽にする仕組み:

- **YouTube のURLを貼るだけ**で、動画ページから読み取った値が空の欄に入ります（`admin/serve.py` から開いたときだけ）
  - 回 … タイトルの「#115」
  - 出演 … タイトルの「【ゲスト：水野朔】」。ゲストが無い番号の回は青山吉能さん1人
  - 配信日 … 公開日時（生配信は配信を始めた日時）の日本時間の日付
  - 動画時間 … 動画の長さ。生配信だった動画には「生配信」タグも付けます
  - すでに値が入っていて YouTube と違うときは書き換えず、「YouTube と違います」のボタンを出します（押すと合わせます。2秒以内の動画時間の差は無視）。同じ動画の回が登録済みのときも知らせます
- **配信日**は「2026/10/22」「20261022」「10/22」など好きな書き方で入力でき、`2026.10.22` の形にそろいます。新しい回では「前回の2週間後」のボタンも出ます
- **YouTube** は `youtu.be/…`・`live/…` のURLや動画IDだけでも、`https://www.youtube.com/watch?v=…` の形にそろいます
- **コーナー**は「＋ 本日のテーマ」などのボタンで選び、時刻を入れます（キーワード「本日のテーマ@45:05」として保存）。ボタンの並びはサイトの index.html の「コーナー」の絞り込みボタンと同じもので、最近よく使う順です。ラッキーボタンはゲスト（`lucky-button.json`）、結束バンドと私は曲（`kessokuband_watasi.json`）、本日のテーマはテーマ（`todays-theme.json`）、ぼっち予想テストは問題・お題（`bocchi-test.json`）、ピックアップキャラクターはキャラクター（`pickup-character.json`、これまでに入れた名前が候補に出ます）の欄も付きます。キーワードの欄にコーナー名を打っても、コーナーの欄に移ります
- **キーワード**は「語」と「時刻」の行。打つと登録済みの語が候補に出ます（読みでも探せます。↑↓で選んで Enter かクリック）。「まとめて入力」や、語の欄への複数行の貼り付けで「語@12:34」「12:34 語」「語 12:34」を一度に入れられます。▶ でその時刻から YouTube で開けます
- 保存するとき、元からある語は元の並びのまま、新しく足した語・コーナーは時刻の位置に入ります（時刻なしは先頭のタグの後ろ）
- **出演**は4人のボタンとゲストの欄。1人なら文字、複数なら配列で保存します（今までのデータと同じ）
- **ラッキーボタンのゲスト・結束バンドと私の曲**は、キーワードの時刻から候補が出ます
- **コーナーの中身はサイトの検索に出ます**：サイトでそのコーナーを検索すると（コーナー検索のボタン、または検索語がコーナー名そのもの）、カードの「ゲスト：…」「パーソナリティ：…」の行が、その回の中身（ゲスト・曲・テーマ・問題・キャラクター）に変わります。中身を入れていない回はいつもの表示のままです。いくつかのコーナーで絞り込んだときは、ラッキーボタン → 結束バンドと私 → 本日のテーマ → ぼっち予想テスト → ピックアップキャラクター の順で、その回に中身があるものが出ます（`main.js` の `CORNER_TEXTS`）
- **関連リンク**はポストのURLを貼ると種類と表示名（「#115 オフショット」など。同じ名前が並ぶと①②）が入ります。並べ替えは行の右端のつまみ（⠿）をドラッグします（つまみを選んで ↑↓ キーでも動かせます）

## サムネは自動で入ります

- 回を保存すると、その場で YouTube から `mqdefault.jpg` を取ってきて `thumbnails/<回>.jpg` に置きます（新しい回・YouTube のURLを変えた回・サムネが無い回）。取れなかったときもJSONは保存され、フォームに理由と「もう一度取得」が出ます
- 別の画像にしたいときは、フォームのサムネ欄に画像をドロップ・貼り付け（⌘V）・「画像を選ぶ」。320×180 に切り抜いて、次の保存で書き込みます
- 「YouTube から取り直す」で、YouTube 側でサムネが差し替えられたときに取り直せます
- 回の名前を変えるとサムネのファイル名も変わり、回を消すとサムネはバックアップへ移ります

## 検索・表示の決まり（見やすさ・使いやすさ）

- 検索は、タイトル・出演・キーワードを1つずつ区切って探します（別々のキーワードがつながって当たることはありません）。全角の「～」と「〜」は同じ文字として扱います
- 読み（`readings.json`・`keywords.json`）のうち2文字以下のもの（「いく」「さく」など）は、検索語がその読みそのもののときだけ使います（「長谷川育美」で「ファーストテイク」の回まで拾わないように）
- 「#36 えろおんなじょうし」のように番号＋読みで探しても、時刻へのリンクが付きます。コーナーを2つ以上選んだときも、それぞれの時刻へのリンクが付きます
- 出演者・コーナー・年で絞ったときは、番号のない特殊回（京まふ大作戦・CENTRAL STATION など）も含めます（何も絞っていない一覧では従来どおり出しません）
- 0件のときは、言い換えのヒントと「検索と絞り込みをリセット」のボタンを出します
- 補助の灰色の文字（公開日時・動画時間・下のナビなど）は、白地で 5:1、ダークで 5:1 以上の濃さにしています。カラーテーマは、白い文字が読める濃さにカード・ボタン・画面の面を調整し、イエローだけは文字を濃い茶色にしています（ピンク・グリーンの「表示数」は大きな太字なので、テーマの色のままです）
- 選択中のフィルタのタグが無いときは、タグ用の帯の高さを取りません
- モーダル（このサイトについて・沿革・関連リンク・タイムスタンプ）は、開くとフォーカスが中へ移り、後ろのページへは Tab で移れません。閉じると開いたボタンへフォーカスが戻ります。スマホのフィルタ画面は Esc でも閉じます
- 別のタブで登録・削除したタイムスタンプは、このタブにもすぐ反映されます（古い内容で上書きして消さないように）
- 同じ条件の検索をやり直しても、履歴（「戻る」）は増えません。Alt/⌘+← などブラウザの「戻る」のキーは、ページ送りに使いません

## 安全のための仕組み

- 保存のたびに、書き換える前・消す前のファイルを `admin/backup/<日時>/` に残します（新しい50回分。`thumbnails/114.jpg` などフォルダの形のまま）。間違えたときはそこから戻してください
- 編集ツールを開いた後にエディタ等で同じJSONを書き換えた場合は、上書きせずに知らせます（「最新を読み込む」を押すと編集中の内容を残したまま読み直せます）
- 保存できるのは上の10個のJSONと `thumbnails/<回>.jpg` だけで、サムネを取りに行くのは `i.ytimg.com` だけ、自動入力のために読むのは `www.youtube.com/watch?v=<動画ID>` のページだけです（読むだけで何も書きません）。保存用サーバーはこのPCの中（127.0.0.1）からしか開けません
- `admin/serve.py` でサイトを開いているときは、手元だけ `sw.js` の代わりに「何もしない sw.js」を返します（古いキャッシュのせいで保存した内容が見えなくなるのを防ぐため。本物の `sw.js` は変えていません）
- プレビューは `admin/preview/` で配信します。保存前の内容は保存用サーバーのメモリに置くだけで、ファイルには書きません（サーバーを止めると消えます）。プレビューの `index.html` にだけ、配信するときに小さなスクリプトを足して、Service Worker を登録しない・ローディング画面を出さない・お気に入りなど（localStorage）と「戻る」の履歴を汚さないようにしています（サイトのファイルは書き換えません）。テーマだけは、プレビューの中で選ぶと本物にも書きます（編集ツールとサイトも同じ色にするため）
- `admin/serve.py` 以外（VS Code の Live Server など）から開いた場合は直接保存できないので、保存すると変更したJSONとサムネ画像がダウンロードされます（サイトのプレビューも出ません）

## 公開について

`admin/`（編集ツールと、保存のたびに残るバックアップ `admin/backup/`）は公開されません。デプロイの設定（`.github/workflows/deploy.yml`）が、公開する直前に `admin/` を取り除いてからまとめるので、フォルダごとGitHubにアップしても `searchtheradio.com/admin/` には何も出ません。それ以外のファイル（このREADMEを含む）はこれまでどおりフォルダ全体が公開されます。
