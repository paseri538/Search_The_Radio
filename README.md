# さーち・ざ・らじお！

『ぼっち・ざ・らじお！』のエピソードを探せる**非公式**の検索サイトです。

🔗 **https://searchtheradio.com/**

> 番組や関係者の公式サイトではありません。動画はすべて YouTube の公式チャンネルにつながります。<br>
> ©はまじあき／芳文社・アニプレックス（詳しくは[著作権と免責事項](#著作権と免責事項)）

---

## できること

- **キーワード検索**　タイトル・出演者・話題で探せます。ひらがな・読み・愛称でも見つかります
- **絞り込み**　出演者・公開年・コーナー・その他（公開録音・生配信）を組み合わせて絞れます
- **時刻へジャンプ**　キーワードやコーナーで探すと、その話題が始まる時刻から YouTube で開けます
- **お気に入り・タイムスタンプ**　気になった回や場面を、自分のブラウザに保存できます
- **ランダム・再生リスト作成**　適当に1回選んだり、表示中の回をまとめて再生したりできます
- **カラーテーマ**　ホワイト・ダーク・ピンク・イエロー・ブルー・レッド・グリーンの7色
- **スマホのアプリのように使える**　ホーム画面に追加すると、オフラインでも開けます（PWA）

## 公開のしかた

GitHub にアップ（push）すると、GitHub Actions（`.github/workflows/deploy.yml`）が自動で GitHub Pages に公開します。

- `sw.js` の版の番号（`SW_VERSION`）は、公開のたびに自動で書き換わります。手で直す必要はありません
- `admin/`・`CLAUDE.md`・`.claude/` は、公開する直前に取り除かれます。うっかりアップしても `searchtheradio.com/admin/` には何も出ません

## データの登録（編集ツール）

JSON を直接書かなくても、フォームに入力するだけで回・サムネ・検索ワード・沿革を登録できます。

### 使い方

1. `admin/start.command` をダブルクリックします。ブラウザで編集ツール（`http://localhost:8790/admin/`）が開きます
2. 上のタブで、**エピソード**・**検索ワード**・**沿革**を切り替えます
3. 「＋ 新しい回」を押して YouTube の URL を貼ると、回・出演・配信日・動画時間・サムネが自動で入ります
4. コーナー・キーワード・関連リンクを入力します。右側のプレビュー（本物のサイト）が、1秒ほどで入力どおりに描き直されます
5. 「保存」（⌘S）で、変わったファイルとサムネをまとめて書き込みます
6. 保存したファイルを GitHub にアップすると、サイトに反映されます

> 初回に「開発元を確認できない」と止められたら、右クリック →「開く」で一度だけ許可してください。

<details>
<summary><b>画面の見方</b></summary>

- **エピソード**　左から「一覧／入力フォーム／サイトのプレビュー」
- **検索ワード**　`keywords.json` と `readings.json` の表。右端の数は、その語が出てくる回の数です（「該当なし」なら書き方の違いを疑ってください）。「試す」で、保存前にヒット数の目安が分かります
- **沿革**　`history.json` の出来事。新しい順に並び、保存すると日付の位置に入ります
- 保存するまでは手元に溜まり、一覧に「● 未保存」「● 新規」「削除予定」と出ます（タブにも点が付きます）
- 保存しても、**変えていない回の行は1文字も変わりません**
- 左上のロゴを押すと、「ぼっち・ざ・ひすとりー！」「出演情報（YPIK SCHEDULE）」の編集ツールへ切り替えられます。止まっているサイトは、選ぶと自動で起動します
- 編集ツールの色は、サイトのカラーテーマと同じになります

</details>

<details>
<summary><b>入力を楽にする仕組み</b></summary>

- **YouTube の URL を貼るだけ**で、空の欄に次の値が入ります
  - 回 … タイトルの「#115」
  - 出演 … タイトルの「【ゲスト：水野朔】」。ゲストが無い回は青山吉能さん1人
  - 配信日 … 公開日時（生配信は配信を始めた日時）の日本時間の日付
  - 動画時間 … 動画の長さ。生配信だった動画には「生配信」のタグも付けます
  - すでに値が入っていて YouTube と違うときは書き換えず、「YouTube と違います」のボタンを出します（2秒以内の動画時間の差は無視）
- **配信日**は「2026/10/22」「20261022」「10/22」など好きな書き方でよく、`2026.10.22` の形にそろいます。新しい回では「前回の2週間後」のボタンも出ます
- **YouTube の URL** は `youtu.be/…`・`live/…`・動画IDだけでも、`https://www.youtube.com/watch?v=…` の形にそろいます
- **コーナー**は「＋ 本日のテーマ」などのボタンで選び、時刻を入れます（キーワード「本日のテーマ@45:05」として保存）。ボタンは最近よく使う順です。コーナーによっては中身の欄も付きます
  - ラッキーボタン → ゲスト
  - 結束バンドと私 → 曲
  - 本日のテーマ → テーマ
  - ぼっち予想テスト → 問題・お題
  - ピックアップキャラクター → キャラクター（これまでに入れた名前が候補に出ます）
- **キーワード**は「語」と「時刻」の行です。打つと登録済みの語が候補に出ます（読みでも探せます）。「まとめて入力」や複数行の貼り付けで、「語@12:34」「12:34 語」「語 12:34」を一度に入れられます
- **動画を見ながら時刻を入れる**　YouTube の URL がある回は、フォームの上に動画が出ます（閉じたあとは「▶ 動画を見ながら時刻を入れる」で再表示）。「今の時刻を入れる」（⌥T）で、再生中の時刻を欄に入れられます。キーワードの行の ▶ を押すと、動画がその時刻へ飛びます
  - ⌥J／⌥L … 1秒戻る・進む
  - ⌥U／⌥O … 5秒戻る・進む
  - ⌥⇧J／⌥⇧L … 10秒戻る・進む
  - ⌥K … 再生・一時停止
- **出演**は4人のボタンとゲストの欄です
- **関連リンク**はポストの URL を貼ると、種類と表示名（「#115 オフショット」など）が入ります。並べ替えは右端のつまみ（⠿）をドラッグします

</details>

<details>
<summary><b>プレビュー・スクショ・スマホで見る</b></summary>

- 右側のプレビューは**本物のサイト**です。「この回」「一覧」、「スマホ／PC」の幅を切り替えられます
- まだ保存していないサムネも、プレビューには出ます
- プレビューのカードをクリックすると、その回がフォームに読み込まれます
- **スクショ**　カメラのボタンで、プレビューを見えているとおり PNG で保存します
  - `admin/chrome-shot` の Chrome アドオンを入れておくと、「このタブを共有しますか」と聞かれなくなります（入れ方は `admin/chrome-shot/使い方.txt`）
- **スマホで見る**　保存前のプレビューを、スマホから HTTPS の URL・QR コードで開けます（Cloudflare のトンネルを使います。仕組みは `admin/serve.py` の冒頭の説明）

</details>

<details>
<summary><b>サムネ</b></summary>

- 回を保存すると、その場で YouTube から `mqdefault.jpg` を取ってきて `thumbnails/<回>.jpg` に置きます（新しい回・URL を変えた回・サムネが無い回）
- 取れなかったときも JSON は保存され、フォームに理由と「もう一度取得」が出ます
- 別の画像にしたいときは、サムネの欄に画像をドロップ・貼り付け（⌘V）・「画像を選ぶ」。320×180 に切り抜いて、次の保存で書き込みます
- 「YouTube から取り直す」で、YouTube 側で差し替えられたサムネを取り直せます
- 回の名前を変えるとサムネのファイル名も変わり、回を消すとサムネはバックアップへ移ります

</details>

<details>
<summary><b>確認用サーバー（admin/serve.py）</b></summary>

サイトと編集ツールを配信し、保存・プレビュー・YouTube の読み取りを受け付けるサーバーです。

- サーバーは裏で動き続けます。止めなくてかまいません（Mac の再起動・ログアウトで止まります）。止めたいときは `admin/stop.command`
- もう一度 `start.command` を押しても、動いているサーバーを使うだけで増えません
- サイトは `http://localhost:8790/`、編集ツールは `http://localhost:8790/admin/`（ぼっち・ざ・ひすとりー！は 8765 番、YPIK SCHEDULE は 8780 番。同時に動かせます）
- ターミナルで動かすときは `python3 admin/serve.py`（ブラウザを開かないなら `--no-browser`、裏に回さないなら `--here`）
- **ファイルが変わると、開いているページが自動で新しくなります**

  | 変わったもの | サイトのタブ | 編集ツール |
  | --- | --- | --- |
  | `style.css` | 読み直さずに差し替え | プレビューだけ差し替え |
  | `index.html`・`main.js` など | 読み直す（検索の状態はそのまま） | プレビューだけ読み直す |
  | JSON・サムネ | 読み直す | ほかの場所で書き換えたときだけ読み直す |
  | `admin/admin.js` など | ― | 読み直して、開いていた回を開き直す |

  - 編集ツールに未保存の変更があるうちは読み直さず、保存したときに読み直します
  - この仕組み（`admin/live.js`）は手元で配信するときだけ差し込むので、公開したサイトでは動きません
- `admin/serve.py` を書き換えると、動いているサーバーが自分で新しい版に入れ替わります
- 保存・エラーの記録は `admin/serve.log`

</details>

<details>
<summary><b>安全のための仕組み</b></summary>

- 保存のたびに、書き換える前・消す前のファイルを `admin/backup/<日時>/` に残します（新しい50回分）。間違えたときはそこから戻せます
- 編集ツールを開いた後に、エディタなどで同じ JSON を書き換えた場合は、上書きせずに知らせます
- 書き込めるのは10個の JSON と `thumbnails/<回>.jpg` だけです。外へ取りに行くのは、サムネ（`i.ytimg.com`）と YouTube の動画ページ（読むだけ）だけです
- サーバーはこの Mac の中（127.0.0.1）からしか開けません
- 手元では、本物の `sw.js` の代わりに「何もしない sw.js」を返します（古いキャッシュのせいで、保存した内容が見えなくなるのを防ぐため）
- 保存前のプレビューの内容はサーバーのメモリに置くだけで、ファイルには書きません
- `admin/serve.py` 以外（VS Code の Live Server など）で開いた場合は、保存すると変更したファイルがダウンロードされます

</details>

## 検索・表示の決まり

<details>
<summary><b>検索のしかた・見た目の細かい決まり</b></summary>

- 検索は、タイトル・出演・キーワードを1つずつ区切って探します（別々のキーワードがつながって当たることはありません）。「～」と「〜」は同じ文字として扱います
- 2文字以下の読み（「いく」「さく」など）は、検索語がその読みそのもののときだけ使います（「長谷川育美」で関係ない回まで拾わないように）
- 「#36 えろおんなじょうし」のように番号＋読みで探しても、時刻へのリンクが付きます
- コーナーで探すと、カードの「ゲスト：…」の行がその回の中身（ゲスト・曲・テーマ・問題・キャラクター）に変わります。中身を入れていない回はいつもの表示のままです
- 出演者・コーナー・年で絞ったときは、番号のない特殊回（京まふ大作戦・CENTRAL STATION など）も含めます
- 0件のときは、言い換えのヒントと「検索と絞り込みをリセット」のボタンを出します
- 灰色の補助の文字（公開日時・動画時間など）は、白地でもダークでもコントラスト比 5:1 以上にしています
- モーダル（このサイトについて・沿革・関連リンク・タイムスタンプ）を開くとフォーカスが中へ移り、閉じると開いたボタンへ戻ります
- 別のタブで登録・削除したタイムスタンプは、このタブにもすぐ反映されます
- 同じ条件の検索をやり直しても、「戻る」の履歴は増えません

</details>
